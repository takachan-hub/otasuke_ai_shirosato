月次Webレポートの見方

毎月お届けしている「月次Webレポート」に出てくる数字や言葉の意味を、具体例を使ってご説明します。レポートを見ながら、気になるところだけ読んでいただければ大丈夫です。

まず見るところは2つだけ「1. 今月の総評」と「今月の改善提案」です。細かい数字は、気になったときに確かめる程度で十分です。

1レポートの全体像

レポートは次の順番で並んでいます。上から順に「結論 → 数字 → 中身 → これからのこと」という流れです。

  1. 今月の総評今月の状況をひとことで。まずここをご覧ください。
  2. 今月の主要数字訪問した人・訪問回数・ページ閲覧数・平均閲覧時間
  3. アクセスの推移月ごとの増え方・減り方をグラフで
  4. どんなアクセスだったかどこから来たか・使った端末・見られたページ
  5. 問い合わせ（・来店）につながる行動電話・LINE・地図などが押された回数
  6. 良かった点・気になる点数字から読み取れたこと
  7. 今月の改善提案ホームページをより良くするためのご提案

「今月の状況」の表示について

◔データ蓄積中
公開して間もない、または訪問がまだ少ない時期です。良し悪しの判断は、データがたまってからお伝えします。
✓大きな問題なし
特に気になる点は見られなかった月です。
!確認したい点あり
「気になる点」に書いた内容があります。悪いという意味ではなく、一緒に確認したいことがある、という印です。
…データ準備中
その月のデータがまだそろっていない状態です。

2主要数字の意味

レポートの「今月の主要数字」には、次の4つが大きく表示されます。

訪問した人（ユーザー数）

その月にホームページを訪れた人の数です。同じ人が何回来ても「1人」と数えます。

「うち初めての人」は、その月に初めて訪れた人の数です。

訪問回数（セッション数）

ホームページが訪問された回数です。同じ人が、日を変えたり時間をあけたりしてまた来ると、もう1回と数えます。

ページ閲覧数（表示回数）

見られたページの合計です。1回の訪問で「トップページ」と「メニュー」を見ると、2ページと数えます。

平均閲覧時間

ホームページが画面に表示されていた時間の、1人あたりの平均です。長いほど、じっくり読まれていると考えられます。

3前月との比較・推移の見方

主要数字の下には、前の月と比べた変化が表示されます。

  • ▲前月比 ＋○％　前の月より増えました。
  • ▼前月比 −○％　前の月より減りました。
  • →前月とほぼ同じ　増減が3％未満のときの表示です。

割合が出ず「前月 ○人」とだけ出る月

前の月のデータがない月や、訪問回数が1か月10回未満と少ない月は、増減の割合を出しても意味が小さいため、前の月の数字だけを並べています。

「アクセスの推移」のグラフ

月ごとの「訪問した人」と「訪問回数」の折れ線グラフです。1か月だけの上がり下がりより、数か月続けて上向きか・下向きかを見るのがおすすめです。季節やお店の行事、天気などでも数字は変わります。

4どこから訪問されたか

ホームページに「何を通って来たか」の内訳です。数字は訪問回数で、割合（％）と一緒に表示されます。

検索（Google等）
Google・Yahoo!などで調べて、検索結果から来た訪問です。お店の名前や「城里町 ○○」などで探してくれた方が多く含まれます。
直接アクセス
URLの直接入力やブックマークなどからの訪問のほか、どこから来たのか分からなかった訪問もここに入ります。とても大事な項目なので、次の項目で詳しくご説明します。
SNS
Instagram・Facebook・YouTubeなど、SNSからと分かった訪問です。
他サイトからのリンク
地域の紹介サイトや取引先のホームページなど、ほかのサイトに貼られたリンクからの訪問です。
広告
インターネット広告からの訪問です。広告を出していない場合は、ふつう表示されません。
その他
メールマガジンなど上のどれにも当てはまらない訪問です。項目が多い月は、少ないものをまとめて「その他」にしています。

5「直接アクセス」について（直接・流入元不明）

「直接アクセス」は、名前から「URLを直接入力した人」だけと思われがちですが、実際にはどこから来たのかの情報が届かなかった訪問もまとめて入る項目です。

LINEやSNSからの訪問は、必ず「直接アクセス」になるわけではありません

同じLINEやSNSからの訪問でも、使っているアプリやスマートフォンの種類、開き方によって、「SNS」や「他サイトからのリンク」に分類されることもあれば、「直接アクセス」に入ることもあります。

そのため、「直接アクセス」のうち、何がどれだけだったのか（QRコードが何回、LINEが何回など）は、レポートでは特定できません。

読み方のヒント

  • チラシにQRコードを載せた月や、LINEでホームページを案内した月に「直接アクセス」が増えた場合は、その取り組みが影響した可能性があります。
  • ただし、上のとおり内訳は分からないため、「QRコードから○回来た」と言い切ることはできません。
  • 常連のお客様がブックマークから見てくださっている場合も、ここに入ります。

6スマートフォン／パソコン

訪れた人が、どの端末でホームページを見たかの内訳です。数字は人数です。

  • スマートフォンiPhone・Androidなど
  • パソコンデスクトップ・ノートパソコン
  • タブレットiPadなど

スマートフォンとパソコンの両方で見た人は、それぞれに数えられることがあります。地域のお店のホームページでは、スマートフォンが多くを占めることがよくあります。

7よく見られたページ・最初に開かれたページ

よく見られたページ

見られた回数（ページ閲覧数）が多いページの上位5つです。お客様が特に関心を持っている情報の目安になります。

最初に開かれたページ

訪問したときに一番はじめに開かれたページの上位5つで、数字は訪問回数です。ホームページの「入口」がどこかが分かります。

8電話・LINE・地図などのクリック

ホームページの中のボタンやリンクが押された回数です。計測の設定をしているホームページだけに表示されます。

問い合わせにつながる行動

電話番号のタップ、LINEボタンのクリック、メールアドレスのクリック、お問い合わせフォームの送信など。

来店・関心につながる行動

Googleマップ・Instagram・YouTubeなどを開いた回数です。地図やSNSのボタンがあるホームページで表示されます。

「押された回数」＝「実際の電話・来店の数」ではありません

電話番号をタップしても、実際には電話をかけなかった場合もあります。反対に、ホームページを見たあとで番号を手で入力して電話をかけた場合は数えられません。お問い合わせへの関心の目安としてご覧ください。

押された場所
「メイン案内」「ページ下部」「画面下ボタン」など、同じボタンがページ内のどこで押されたかを表示する場合があります。
「現在は計測していません」
計測の設定をしていないため、件数が分からない状態です。「0件」とは意味が違います。
「今月は記録がありませんでした」
計測はしていて、その月に押された記録がなかった（0件）という意味です。

9良かった点・気になる点・改善提案

数字から読み取れたことを、当センターが言葉にまとめた部分です。

良かった点・気になる点
その月の数字で目立ったことです。データがまだ少ない時期は、まとめて「評価は、データがたまってからお伝えします。」と表示します。
今月の改善提案
ホームページをより見やすく・使いやすくするためのご提案です。それぞれに「理由」と「期待できること」を書いています。
優先度：高
特に早めの対応をおすすめするご提案に付けています。
対応の区分
「運用保守内で対応」は月額の運用・保守料金の範囲で対応できるもの、「別途有償対応」は別にお見積りが必要なもの、「要相談」は内容を一緒に確認してから決めるものです。
前回からの改善・その後
以前のご提案で実施した改善と、その後の数字の様子です。「今月の総評」の中に表示します。

改善提案は「必ず実施するもの」ではありません

ご提案を見て、実施するかどうかはお客様が決めていただけます。お客様のご承諾なしに作業を進めたり、費用が発生したりすることはありません。改善の必要がない月は、提案がないこともあります。

10数字を見るときの注意

  • レポートの数字は、Googleのアクセス解析サービス「Google アナリティクス 4」の計測データにもとづいています。
  • ブラウザの設定などによっては計測されない訪問もあるため、実際の訪問とぴったり一致するものではありません。増えたか・減ったかの傾向を見る目安としてご覧ください。
  • お店の方やご家族がホームページを確認した分も、数字に含まれることがあります。
  • 数字の変化には、季節・行事・天気・広告など、ホームページ以外の理由も影響します。

分からないところや気になる数字があれば、いつでもお気軽にお尋ねください。
