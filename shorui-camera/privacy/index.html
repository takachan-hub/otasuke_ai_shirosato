プライバシーポリシー

書類撮影アプリにおける情報の取り扱いについて、次のとおり定めます。

制定日：2026年11月4日

1. はじめに

「書類撮影アプリ」（以下「本アプリ」）は、お助けAI城里センター（以下「当センター」）が提供する、領収書や請求書などの書類をスマートフォンで撮影し、画像を整えるWebアプリです。現在は Cloudflare Access により、当センターが許可した方だけが利用できます。

本ポリシーは、本アプリが取り扱う情報と、その利用・保存・保護の方法を説明するものです。公式サイトのその他のページは、本ポリシーの対象ではありません。

2. 機能の提供状況

本ポリシーでは、機能の状況を次のように示します。準備中の記載は、その機能の提供を始めたときに適用します。ただし「7. Google ユーザーデータの取り扱い」は、当センターの代表者が Google アカウントで本アプリとの連携を許可した時点から適用します。提供を始めるときは、実際の内容に合わせて本ページを更新します。

  • 提供中書類の撮影、画像の自動補正、撮り直し、端末への保存
  • 準備中当センターの Google Drive への保存、Google Picker による保存先フォルダの選択、お客様ごとの管理、端末の登録

3. 運営者・お問い合わせ先

4. 取り扱う情報

  • 撮影した書類の画像提供中：撮影と補正はご利用の端末の中で行います。提供中の機能では、画像を当センターのサーバーへ送信しません。
  • ログインに関する情報提供中：Cloudflare Access の認証で使用するメールアドレスなどの情報です。
  • 書類の画像の送信準備中：利用者が送信の操作をした画像を、当センターの Google Drive へ保存します。
  • Google API から受け取る情報準備中：「7. Google ユーザーデータの取り扱い」に記載します。
  • お客様と端末の管理情報準備中：管理用の呼び名、端末の管理用の名前、登録日時、最終利用日時、保存の記録（日時、結果、画像の大きさ、画像の内容から計算した識別値、Google Drive 上のファイルの識別子）です。
  • 不正利用を防ぐための情報準備中：回数の制限のために接続元の情報を扱います。元の値に戻せない形に変換して扱います。

本アプリは、位置情報、連絡先、端末の広告識別子を取得しません。本アプリと本ページでは、アクセス解析や広告のための Cookie・ツールを使用しません。本アプリで使用する Cookie は、Cloudflare Access のログインのためのものと、準備中端末の登録のためのものです。

5. 利用目的

  • 書類の撮影、画像の補正、端末への保存の機能を提供するため
  • 準備中お預かりした書類を、ご契約に基づく業務に利用するため
  • 本アプリの利用者の確認、不正利用の防止、障害への対応のため
  • お問い合わせに対応するため

6. 書類の保存先と管理準備中

送信された書類の画像は、当センターの Google Drive の、お客様ごとのフォルダに保存します。保存先のフォルダは当センターが用意し、管理します。書類の管理主体は当センターです。

保存先はサーバーで決定し、利用者が保存先を指定することはできません。画像は転送の処理中に一時的に扱い、本アプリのサーバーには保存しません。本アプリには、お客様が保存済みの書類を一覧・閲覧する機能はありません。

保存した書類は、ご契約に基づく業務のために当センターの担当者が確認します。

7. Google ユーザーデータの取り扱い準備中

本章は、当センターの代表者が Google アカウントで本アプリとの連携を許可した時点から適用します。現時点では、Google Drive への保存の機能はお客様に提供していません。

連携の方法

本アプリは、当センターの代表者が当センターの Google アカウントで許可した権限により、Google Drive を利用します。本章の「Google アカウントの利用者」とは、この連携を許可した当センターの代表者をいいます。本アプリのお客様に Google アカウントでのログインをお願いすることはなく、お客様の Google アカウントの情報を取得することもありません。

お客様の書類と Google API の情報の区別

本章の「Google API から受け取った情報」とは、本アプリが Google の API を通じて取得するフォルダやファイルの情報（識別子・名前など）をいいます。お客様が本アプリから送信する書類の画像は、Google API から受け取る情報ではなく、お客様から当センターへ直接送信されるものです。

本アプリは、Google Drive API を通じて保存済み書類の本文や画像を取得・解析する機能を設けていません。保存した書類は、当センターの担当者が契約に基づく業務のため、Google Drive 上で直接確認します。

要求する権限

本アプリが Google アカウントに要求する権限は https://www.googleapis.com/auth/drive.file だけです。この権限は、本アプリが作成したファイルと、当センターが Google Picker で選択したフォルダを扱うためのものです。Google Drive 内のその他のファイルを閲覧・検索するためのものではありません。Gmail、連絡先、カレンダーなどへのアクセスは要求しません。

取得・利用する情報と目的

  • OAuth のトークン：Google Drive へ書類を保存するため、および Google Picker を表示するために使用します。
  • Google Picker で選択したフォルダの情報（識別子、名前、種類、ゴミ箱にあるか、所有者か、共有ドライブ上か、ファイルを追加できるか）：お客様ごとの保存先として登録し、保存の前に保存先が正しいことを確認するために使用します。
  • 本アプリが保存したファイルの情報（識別子、保存先、本アプリが付けた管理用の識別子）：正しいフォルダに保存されたことの確認と、二重の保存の防止に使用します。

本アプリが Google Drive 上で行う操作は、保存先フォルダの確認、書類の画像の保存、二重の保存を防ぐための確認、および保存先に誤りがあった場合に本アプリ自身が作成したファイルを削除することに限ります。ファイルやフォルダの共有設定の変更、公開リンクの作成は行いません。

保存する場所と期間

  • フォルダの識別子と名前、本アプリが保存したファイルの識別子：Cloudflare D1 に保存します。お客様の保存先の管理、保存の確認、二重の保存の防止に必要な間保存し、ご契約の終了や保存先の変更などで必要がなくなったものは削除します。具体的な保存期間と削除の条件は、Google Drive への保存の機能を提供するまでに定め、本ページに記載します。
  • Google の認証情報：サーバーの秘密情報の保管機能にだけ保存し、連携を取り消すときに削除します。
  • Google Picker のためのアクセストークン：管理画面のブラウザのメモリの上でだけ使用し、保存しません。

Google API から受け取った情報について行わないこと

  • 広告（パーソナライズド広告、リターゲティング、興味・関心に基づく広告を含む）への利用
  • 販売、データブローカーや情報再販業者などへの移転
  • 本ポリシーに記載した目的以外での利用、および「9. 第三者提供と外部サービス」に記載する場合を除く第三者への提供・転送
  • 一般化された（個人向けでない）AI・機械学習モデルや基盤モデルの開発、改良、学習への利用。本アプリは、Google Workspace API をこれらの目的に使用しません
  • 信用力の判断や融資を目的とした利用
  • 本章に記載した情報の保存を除く、データベースや恒久的な複製の作成
  • 人による閲覧（Google アカウントの利用者が特定のファイルやデータの閲覧に明確に同意し、その記録がある場合、セキュリティ上の問題の調査に必要な場合、法令の遵守に必要な場合を除きます）

Google のポリシーへの準拠

本アプリによる Google API から受け取った情報の使用は、Google API Services User Data Policy（限定使用の要件を含む）に準拠します。

Shorui Camera's use of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

Google Workspace のスコープから受け取った情報の使用は、Google User Data Policy（限定使用の要件を含む）に準拠します。Google Workspace user data and developer policy もあわせて確認し、取り扱います。

The use of information received from Google Workspace scopes will adhere to the Google User Data Policy, including the Limited Use requirements.

8. 保存期間と削除

  • 端末に保存した画像提供中：利用者ご自身で削除できます。
  • Google Drive に保存した書類準備中：契約期間中は、業務に必要な書類を保存します。契約が終了するときは、お客様と返却・削除の方法を確認します。契約終了後の削除の期限は、個別の契約で定めます。法令上の保存義務がある場合は、その義務を踏まえて取り扱います。
  • 管理情報・記録準備中：本アプリの提供と不正利用の防止に必要な間保存し、必要がなくなったものは削除します。Google API から受け取る情報については、「7. Google ユーザーデータの取り扱い」の「保存する場所と期間」に記載します。

削除のご依頼は、「3. 運営者・お問い合わせ先」へご連絡ください。

準備中当センターは、当センターの Google アカウントの設定から、本アプリとの連携をいつでも取り消せます。取り消すと、本アプリは Google Drive へ書類を保存できなくなります。すでに保存した書類はそのまま残ります。連携を取り消すときは、サーバーに保存した Google の認証情報も削除します。

9. 第三者提供と外部サービス

法令に基づく場合を除き、取り扱う情報を第三者へ販売・提供しません。本アプリの提供のために、次の外部サービスを利用します。

  • Cloudflare, Inc.（本アプリの配信、Cloudflare Access による認証、準備中書類の画像の転送処理、管理情報の保存）：プライバシーポリシー
  • Google LLC（準備中Google Drive への書類の保存、Google アカウントの認証、Google Picker）：プライバシーポリシー

10. 安全管理

現在行っていること

  • 通信は HTTPS で暗号化します。
  • Cloudflare Access により、当センターが許可した方だけが本アプリを利用できます。
  • 撮影と補正は端末の中で行い、提供中の機能では画像をサーバーへ送信しません。
  • 本アプリの画面から外部のサーバーへ通信できないように制限しています。

Google Drive との連携の提供に合わせて行うこと準備中

  • Google の認証情報は、サーバーの秘密情報の保管機能に保存し、ブラウザやソースコードには保存しません。
  • 保存先はサーバーで決定し、他のお客様のフォルダへ保存されないよう、保存の前後に確認します。
  • Google Drive の権限は必要最小限（drive.file）に限定し、書類を一般公開・リンク共有しません。

11. 本ポリシーの変更

本アプリの機能や取り扱う情報を変更する場合は、本ページを更新します。Google から受け取る情報の使い方を変更するときは、事前に本ページを更新し、Google アカウントの利用者に改めて同意を求めます。
