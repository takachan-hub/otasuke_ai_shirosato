書類撮影アプリ

領収書や請求書などの書類をスマートフォンで撮影し、読みやすい画像に整えるWebアプリです。

書類撮影アプリとは

「書類撮影アプリ」は、お助けAI城里センターが提供する、領収書や請求書などの書類をスマートフォンで撮影し、読みやすい画像に整えるWebアプリです。

現在は Cloudflare Access により、当センターが許可した方だけが利用できます。一般の方への提供は行っていません。

機能の提供状況

  • 提供中書類の撮影
  • 提供中画像の自動補正（書類の切り取り、傾き・ゆがみの補正、明るさの調整）
  • 提供中撮り直し
  • 提供中補正した画像の端末への保存
  • 準備中当センターの Google Drive への保存
  • 準備中Google Picker による保存先フォルダの選択（当センターの管理者が行います）
  • 準備中お客様ごとの管理と、端末の登録

提供中の機能では、撮影と補正はご利用の端末の中で行い、画像を当センターのサーバーへ送信しません。

Google Drive を利用する目的準備中

お客様からお預かりする書類の画像を、お客様ごとのフォルダに分けて当センターが管理するために、当センターの Google Drive を利用する予定です。

  • 連携は、当センターの代表者が当センターの Google アカウントで行います。お客様に Google アカウントでのログインをお願いすることはありません。
  • Google アカウントに求める権限は https://www.googleapis.com/auth/drive.file だけの予定です。本アプリが作成したファイルと、当センターが Google Picker で選択したフォルダを扱うための権限で、Google Drive 内のその他のファイルを閲覧・検索するためのものではありません。
  • お客様が本アプリから送信する書類の画像は、Google API から受け取る情報ではなく、お客様から当センターへ直接送信されるものです。本アプリは、Google Drive API を通じて保存済み書類の本文や画像を取得・解析する機能を設けていません。
  • ファイルの共有設定の変更や、公開リンクの作成は行いません。
  • Google API から受け取った情報を、広告、販売、一般化された（個人向けでない）AI・機械学習モデルの学習に使用しません。詳しくはプライバシーポリシーをご覧ください。

本アプリによる Google API から受け取った情報の使用は、Google API Services User Data Policy（限定使用の要件を含む）に準拠します。

Shorui Camera's use of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.
